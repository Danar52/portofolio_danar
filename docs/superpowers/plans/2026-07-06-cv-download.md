# CV/Resume PDF Download Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let visitors download Danar's CV as a PDF from the homepage hero button, with the file manageable from the existing admin panel.

**Architecture:** One new nullable `cv_url` column on the existing `profile` table. Admin panel gets an upload/remove control that reuses the existing photo-upload pattern (`uploadFile()` helper, `portfolio-images` storage bucket, new `cv/` folder). Homepage hero gets a second button, hidden by default, shown and wired to a forced-download URL once `cv_url` is fetched.

**Tech Stack:** Vanilla JS (no framework, no bundler), Supabase (Postgres + Storage), static HTML/CSS.

## Global Constraints

- This is a static site with **no test runner and no `package.json`** — every task's "test" step is a manual verification using the browser preview tools, not an automated test. Do not invent a test framework.
- Follow the existing code style exactly: plain functions attached to `window` implicitly (admin.js is a non-module script, uses inline `onclick="..."`), while `index.js` is `type="module"` and must use `addEventListener` (no inline `onclick`) — these are two different scripts with two different rules, don't mix them up.
- Reuse existing helpers/classes instead of creating new ones: `uploadFile(file, folder)` (admin.js:67), `.photo-upload-btn` / `.form-section-title` / `.btn.btn-danger.btn-sm` CSS classes, `showToast()`.
- No new Supabase Storage bucket — reuse `portfolio-images`, add files under a `cv/` folder prefix.
- No new HTML pages.

- [ ] **Step 2: Add `handleCvChange()` and `removeCv()` functions**

Add these two functions right after `removePhoto()` (after line 423 in the original file, i.e. right after the closing `}` of `removePhoto`):

```js
    async function handleCvChange(input) {
      const file = input.files[0];
      if (!file) return;
      if (file.type !== 'application/pdf') {
        showToast('File harus PDF', 'error');
        input.value = '';
        return;
      }
      const overlay = document.getElementById('cvSavingOverlay');
      overlay.classList.add('show');
      const url = await uploadFile(file, 'cv');
      if (!url) { overlay.classList.remove('show'); return; }
      const { error } = await db.from('profile').update({ cv_url: url }).eq('id', profileId);
      overlay.classList.remove('show');
      if (error) { showToast('Gagal menyimpan CV', 'error'); return; }
      showToast('CV berhasil diupload! 📄');
      loadProfile();
    }

    async function removeCv() {
      const { error } = await db.from('profile').update({ cv_url: null }).eq('id', profileId);
      if (error) { showToast('Gagal hapus CV', 'error'); return; }
      showToast('CV dihapus!');
      loadProfile();
    }
```

function renderCvButton(p) {
